## 3. 비상 계획

| 상황 | 대응 |
|---|---|
| **A. 웹은 뜨는데 느리다** | 배포 API는 미국 서부라 응답이 약 0.25초다(performance.md 4장). 지도를 크게 움직이지 말고 검색 · 지역 선택 위주로 진행한다 |
| **B. 배포 사이트 · API가 안 뜬다** | 로컬로 바꾼다. `uvicorn app.main:app`(:8000) + `cd web && npm run dev`(:3000), 주소는 http://localhost:3000. 로컬 DB가 덤프 v6와 같아야 2장 값이 같다 |
| **C. 인터넷이 안 된다** | 지도 타일(네이버)이 없어 로컬도 지도가 비어 보인다. **녹화 영상**으로 바꾸고, 목록 · 상세 화면은 로컬 서버로 보여 줄 수 있다 |
| **D. 특정 화면만 오류** | "다시 시도"를 한 번 누른다. 그래도 안 되면 다음 순서로 넘어가고 슬라이드의 화면 캡처로 설명한다 |
| **E. 성남 역이 지도에 안 보인다** | 예전 역 목록이 캐시된 것이다. 강력 새로고침(Ctrl+Shift+R) 또는 시크릿 창 |
| **F. 발표 PC에서 슬라이드가 안 열린다** | PDF 슬라이드로 진행한다 |

## 4. 시연 뒤 받을 만한 질문

| 질문 | 답의 요지 | 근거 |
|---|---|---|
| 추정 연봉이 왜 낮나 | 국민연금 소득 상한 때문에 고연봉 회사일수록 낮게 나온다. 그래서 "≥ 하한"으로만 쓴다 | validation.md 3장 |
| 다른 지역은 | 서울 · 성남만. 성남에 쓴 방식(주소 · 출입구 파일, 국토부 전월세)으로 다른 시도 넓힐 수 있다 | decisions/010 |
| 데이터는 언제 바뀌나 | 국민연금이 매월 공개, 지금은 로컬에서 적재 · 검증 후 반영(수동) | runbook 4장 |
| 회사 위치가 정확한가 | 약 1.3만 곳만 건물 단위, 나머지는 도로 · 동 중심(점선 핀) | validation.md 1장 |
| AI를 썼나 | 서비스 기능에는 LLM · 임베딩을 쓰지 않았다. 통계는 SQL로 계산한다 | CLAUDE.md, SPEC |
