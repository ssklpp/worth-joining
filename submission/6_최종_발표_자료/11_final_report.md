## 3. 만든 것

### 3.1 기능

| 기능 | 내용 |
|---|---|
| 지도 메인 | 지도 범위 안 회사 핀(12개월 증감 · 퇴사율 · 연봉), 왼쪽 목록 10 · 20곳씩, 역 이름 이동, 지역(구) 선택 |
| 검색 | 회사명 · 사업자번호 앞 6자리 · 업종, 결과 없을 때 이유 안내 |
| 회사 상세 | 회사 체력 3줄(성장 · 안정 · 연봉)과 업종 안 위치, 월별 추이, DART 재무, 채용 검색 바로가기 |
| 근처 주거비 | 회사 1km 안 역 최대 3곳의 원룸 시세와 월급 대비 부담률 |
| 역 시세 | 반경 500 · 750m × 6 · 12 · 24개월, 24개월 추이, 역 3곳 비교 |
| 회사 비교 | 3곳의 가입자 지수 그래프와 지표 표, 주소로 공유 |
| 투명성 | 모든 화면에 기준월 · 출처, 추정치 한계 문장, 계산 방법 페이지 |

### 3.2 구조

```
공공데이터 → pipeline/ (Python 배치, 품질 검사) → MariaDB raw → core → mart → app/ (FastAPI, 읽기 전용) → web/ (Next.js, 지도 + 패널)
```

- **3계층 DB:** raw는 원본 보존, core는 정규화, mart는 미리 집계한다. API는 mart만 읽어 요청 때 집계하지 않는다.
- **통계는 SQL로:** 윈도 함수 · `PERCENTILE_CONT` · 공간 인덱스 · 월 파티션을 쓴다. SQL은 `sql/`에 파일로 두고 회귀 테스트로 고정했다.
- **회사 잇기:** 출처 사이에 공통 키가 없어, 사업자번호 앞 6자리와 정규화 이름으로 DART와 잇는다(정확 → 유사 85점 이상 → 그 외 연결 안 함).
- **좌표:** 건물번호 없는 주소에 DART 본사 → 상호 검색 → 도로 중심 → 동 중심 4단계로 위치를 준다. 저장 좌표는 주소정보누리집 것만 쓴다.
- **배포:** 로컬에서 적재 · 검증한 결과만 Railway DB에 올리고, API는 사설망으로 DB에 붙는다(10 문서).

## 6. 회고

### 잘한 점

- **SPEC 하나를 기준으로 삼았다.** 구현 지시서(SPEC)를 먼저 쓰고 결정이 바뀌면 SPEC부터 고쳐, 네 트랙이 같은 계약으로 동시에 작업했다. 웹은 API가 준비되기 전에 목 응답과 OpenAPI 타입으로 먼저 만들었다.
- **결정과 문제를 문서로 남겼다.** 결정 10건과 문제 34건(증상 · 원인 · 해결 · 재발 방지)을 기록했다. 같은 문제를 다시 만났을 때 troubleshooting에서 바로 찾았다.
- **숫자를 공개 자료와 대조했다.** 인원 ±6%를 확인했고, 연봉이 늘 낮게 나오는 이유(소득 상한)를 찾아 "하한 추정"으로만 표시했다. 한계를 화면과 발표에서 숨기지 않았다.
- **재고, 고치고, 다시 쟀다.** 느린 쿼리를 EXPLAIN과 부하 측정으로 찾아 전후 숫자로 남겼다.
- **고친 버그는 테스트로 고정했다.** 코드를 되돌리면 실패하는 것을 확인한 테스트로 남겨, 같은 버그가 다시 들어오지 않게 했다.

### 아쉬운 점

- **데이터 갱신이 수동이다.** 국민연금 월 파일을 자동으로 받을 수 없어 cron 대신 사람이 하는 절차가 됐고, 명령도 여러 개다(I-19 · I-20).
- **업종 분류 없는 회사(999999) 처리를 늦게 발견했다.** 서로 다른 업종이 한 분포에 섞인 판정이 10/19 코드 리뷰에서야 나왔다(I-01). 업종 코드 분포를 프로파일링 단계에서 더 봤다면 일찍 막을 수 있었다.
- **배포 DB 반영 순서에서 실수가 있었다.** 수정 전 코드로 만든 표를 한 번 올렸다가 바로잡았다(09 문서 8장). 배포 DB에 올리기 전에 main 기준으로 다시 만드는 것을 절차로 굳혀야 한다.
- **배포 리전이 멀다.** API가 미국 서부에 있어 응답의 절반 이상이 네트워크 왕복이다(I-15).
- **검증 표본이 대기업뿐이다.** 대조한 5곳이 모두 대기업이라 중소기업 정확도는 확인하지 못했다.

### 배운 점

- 공공데이터는 "있다"와 "쓸 수 있다" 사이가 멀다. 스냅샷을 쌓고, 사업장을 회사로 묶고, 공통 키 없이 잇고, 건물번호 없는 주소에 위치를 주는 일이 대부분이었다.
- MariaDB 11.4는 공간 조인을 윈도 함수와 한 쿼리에 넣으면 공간 인덱스를 쓰지 않는다. 실행 계획을 직접 확인해야 한다.
- 이용 조건(좌표 저장 · 지도 키 · 크롤링 금지)이 설계를 정한다. 좌표 출처를 하나로 정하고, 채용은 API 대신 바로가기로 바꿨다.

## 10. 한계

- 추정 연봉은 국민연금 소득 상한 때문에 회사 평균의 하한이며, 개인이나 직무별 연봉이 아니다.
- 서울 · 성남 사업장만 다루고, 국민연금 공개 기준(법인 3인 · 개인 10인) 미만 회사는 없다.
- 회사 위치는 약 1.3만 곳만 건물 단위이고 나머지는 도로 · 동 중심(지도의 점선 핀)이다.
- 역세권 시세는 신고된 계약 기준이라 지금 매물 가격과 다를 수 있다.
- 채용공고는 모으지 않고 검색으로 연결한다.
