## 참고

- 문서는 저장소의 `docs/`에서 복사했습니다. 문서 안의 상대 링크는 저장소 기준이라, 다른 폴더의 문서를 가리키는 링크는 코드 저장소(2번)의 `docs/`에서 열면 됩니다.
- API 키 · DB 비밀번호(`.env`)와 원본 데이터(`data/`)는 넣지 않았습니다. 데이터를 다시 만드는 방법은 4번 가이드에 있습니다.
