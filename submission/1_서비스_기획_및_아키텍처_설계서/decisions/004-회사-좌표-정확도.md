# 004. 회사 지도 좌표: 동 · 도로 중심 기본, DART 본사 주소와 사업장명 검색으로 보강

| 항목 | 내용 |
|---|---|
| 상태 | 채택 · 2026-10-12 |
| 관련 | SPEC Phase 5 · 8, 5.2 `dart_corp` · `geocode_cache`, FR-MAP-06, DR-09, T1-11, [profiling.md](../profiling.md) 6장, 02 문서 8.2-10 |

## 배경

국민연금 사업장 주소는 도로명까지(`…독서당로14길`), 지번은 읍면동까지만 있다. 서울 13개월 모두 건물번호가 0건이라 국민연금 주소만으로는 건물 단위 좌표를 만들 수 없다.

## 결정

회사마다 아래 순서로 좌표를 정하고, 앞 단계에서 얻으면 뒤 단계는 건너뛴다. 모든 좌표는 주소정보누리집(juso)에서 얻는다(4장 이용 조건).

| 순서 | 방법 | `accuracy` | `basis` | 대상 |
|---|---|---|---|---|
| 1 | **DART 본사 주소:** DART 기업개황(`company.json`)의 `adres`를 juso 검색 → 좌표제공 API로 변환 | `building` | `dart_hq` | DART와 매칭된 회사 중 본사 주소의 자치구가 대표 사업장의 자치구와 같은 회사 |
| 2 | **도로명 + 사업장명 검색:** juso 검색 API에 "자치구 + 도로명 + 사업장명"을 넣어, 같은 도로의 결과가 정확히 1건일 때만 채택 | `building` | `name_search` | 지도에 많이 보일 상위 회사(가입자 많은 순, 호출 한도 안에서) |
| 3 | **도로 중심:** 같은 자치구 · 도로명에 있는 건물 좌표들의 중앙값 | `road` | `road` | 도로명 주소가 있는 회사 |
| 4 | **동 중심:** 같은 법정동에 있는 건물 좌표들의 중앙값 | `dong` | `dong` | 나머지 전부(`legal_dong_code`는 모든 행에 있음) |

### 세부 규칙

- **1의 자치구 조건:** 본사와 국민연금 대표 사업장이 다른 곳이면, 본사 위치에 핀을 찍으면 사업장 지표와 위치가 어긋난다. 자치구가 다르면 1을 쓰지 않고 3 · 4로 내려간다.
- **1은 호출이 적다:** Phase 5가 이미 `company.json`을 호출하므로 `adres`를 함께 저장하면 DART 쪽 추가 호출이 없다. juso 호출만 매칭된 회사 수만큼 든다.
- **2의 채택 조건:** 결과가 여러 건이거나 다른 도로면 버린다. 틀린 건물에 찍는 것보다 3의 대략 위치가 낫다.
- **3 · 4의 원천:** 주소정보누리집이 제공하는 건물 위치 파일(예: 위치정보요약DB)이 있으면 서울분을 받아 자치구 · 도로명별, 법정동별 중앙값을 계산한다. API 호출이 필요 없다. 파일을 쓸 수 없으면 검색 API로 동 · 도로마다 건물 몇 곳을 받아 좌표제공 API로 변환한 뒤 중앙값을 낸다. 어느 쪽인지는 T1-11 시작 때 확인한다. **2026-10-13: 파일 방식으로 했다.** "도로명주소 한글"(건물 주소)과 "도로명주소 출입구"(건물 좌표) 서울 파일을 건물관리번호로 붙여, 표본이 아니라 모든 건물의 중앙값을 낸다(docs/validation.md).
- 2025-08 ~ 11 파일에서 도로명 주소의 시도가 법정동 코드와 다른 행(profiling P6)은 3을 건너뛰고 4를 쓴다.

### 저장

- `geocode_cache`는 그대로 주소 → 좌표 캐시로 쓴다. 키 예: 동 중심 `dong:1117013100`, 도로 중심 `road:11170:독서당로14길`, DART 주소는 정규화한 주소 문자열.
- 회사별 최종 좌표는 새 테이블 `company_location`에 둔다. 지도 SQL(`q_map_companies.sql`)은 `rep_addr_key` 대신 이 테이블을 읽는다.
- `dart_corp`에 `adres VARCHAR(300)`을 추가한다.
- 두 DDL은 SPEC 5.2에 반영했다.

### 화면

- `accuracy`가 `building`이 아니면 `approx_location` 플래그를 켜고 속이 빈 핀으로 그린다(03 문서).
- `basis='dart_hq'`이면 팝업에 "본사 주소 기준 위치입니다"를 함께 적는다.
- 같은 동 · 도로 중심에 여러 회사가 겹치므로 지도는 핀을 묶어 개수를 보여 준다.

## 결과

- 모든 서울 회사가 최소 동 단위로 지도에 나온다. 주요 회사(DART 매칭 · 상위 회사)는 건물 단위로 나온다.
- 회사 상세의 1km 범위와 근처 역은 `accuracy`가 낮으면 참고용이다. 화면에 그렇게 적는다.
- 성공률(단계별 회사 수와 비율)은 `docs/validation.md`에 기록한다.
- 2의 실제 성공률은 juso 키를 받은 뒤 상위 회사 수십 곳으로 시험해 보고, 낮으면 대상을 줄이거나 뺀다.
