## 1. 배경

- 구직자가 회사를 판단할 때 쓰는 정보는 대부분 채용공고(회사가 작성)와 익명 리뷰(개인 경험)다.
- 공식 데이터는 이미 공개되어 있다.
  - 국민연금공단: 사업장별 가입자 수, 신규 취득자, 상실자, 고지금액을 매월 공개
  - DART: 공시 대상 법인의 재무제표
  - 서울특별시: 부동산 전월세가 정보(신고된 계약)
- 하지만 이 데이터를 그대로 쓰기는 어렵다.
  - 월별 스냅샷이라 추이를 보려면 여러 달을 직접 쌓아야 한다.
  - 사업장 단위라 회사 단위로 다시 묶어야 한다.
  - 고지금액을 연봉으로 바꾸려면 보험료율과 소득 상한을 반영해야 한다.
  - 국민연금 · DART · 채용공고 사이에 공통 키가 없다.
  - 실거래가는 지번 단위라 "역 주변 시세"를 바로 알 수 없다.

## 2. 해결하려는 문제

> 구직자가 지원하려는 회사에 대해 "사람이 늘고 있는가, 자주 떠나는가, 급여는 어느 수준인가, 지금 뽑고 있는가, 근처에서 살 수 있는가"를 공식 데이터로 빠르게 확인할 방법이 없다.

| # | 세부 문제 | 해결 방향 |
|---|---|---|
| P1 | 추이를 볼 수 없다 | 월별 스냅샷을 누적 적재하고 회사 단위로 집계 |
| P2 | 이직률을 알 수 없다 | 입퇴사 인원을 비율로 바꾸고 업종 내 백분위로 비교 |
| P3 | 급여 추정에 전문 지식이 필요하다 | 기간별 보험료율 기준표로 역산하고 한계를 함께 표시 |
| P4 | 흩어진 데이터를 잇기 어렵다 | 사업자번호 6자리 + 정규화 상호로 단계별 매칭, 신뢰도 기록 |
| P5 | 회사 근처 주거비를 알기 어렵다 | 주소를 좌표로 바꿔 역 반경 500m 시세 집계 |
| P6 | 채용의 성격을 알 수 없다 | 진행 중 공고와 인원 흐름을 겹쳐 채용 신호 제공 |

## 3. 목표 사용자

| 구분 | 사용자 | 주요 사용 장면 |
|---|---|---|
| 1차 | 신입 · 주니어 구직자 | 지원할 회사 고르기, 면접 준비, 여러 합격처 비교 |
| 2차 | 이직 준비 중인 경력자 | 이직 후보 회사의 성장성 · 안정성 점검 |
| 3차 | 대학 취업지원센터 · 취업 컨설턴트 | 상담 시 객관적 근거 자료로 활용 |
| 확장 | 수도권 취업을 준비하는 지방 구직자 | 합격 후 다닐 회사 근처의 전월세 시세와 주거비 부담 확인 |

## 4. 프로젝트 목표

### 사용자 목표

- 회사 하나의 체력(성장 · 안정 · 급여)을 한 화면에서 확인한다.
- 같은 업종 안에서의 상대 위치로 판단한다.
- 추정치의 한계를 알고 해석한다.
- 지원 단계에서 채용 성격과 생활비까지 함께 판단한다.

### 기술 목표

- 수집 → 정제 → DB 모델링 → SQL 분석 → API 제공의 전 과정을 직접 구현한다.
- 멱등 적재, 품질 검사, 스케줄링이 있는 데이터 파이프라인을 운영한다.
- raw → core → mart 3계층 모델, 파티셔닝, 공간 인덱스를 설계하고 근거를 문서로 남긴다.
- 핵심 지표를 윈도 함수 · CTE · 조건부 집계로 계산한다.
- LLM · RAG 등 AI 기능은 사용하지 않는다.

## 5. 차별점

| # | 차별점 | 설명 |
|---|---|---|
| D1 | 회사와 생활을 한 화면에 | 회사 체력과 그 회사에 다닐 때의 주거비를 함께 제공 |
| D2 | 절대값보다 상대 위치 | 지표마다 업종 내 백분위 제공 |
| D3 | 채용의 성격 | 성장형 / 결원 충원형 채용 가능성 표시 |
| D4 | 한계의 투명한 공개 | 하한 추정, 표본 부족, 매칭 방식을 화면에 표시 |
| D5 | 바로 조회 | 회원가입 · 결제 없음 |

이 서비스는 기업 리뷰를 대체하지 않는다. 통계로 교차 확인하는 도구다. 팀 분위기, 업무 강도, 직무별 연봉은 다루지 않는다.

## 6. 범위

### 포함

| 영역 | 내용 |
|---|---|
| 회사 데이터 | 국민연금 가입 사업장 내역(전국. 법인 3인 이상, 개인 10인 이상 공개분), DART 기업개황 · 주요 재무계정 |
| 주거 데이터 | 서울 연립다세대 · 오피스텔 전월세 실거래가(최근 24개월), 도시철도 역 위치 |
| 채용 데이터 | 사람인 채용공고 요약(공고 번호, 마감일, 연봉 코드, 근무지, 원문 링크) |
| 기능 | 검색, 회사 상세, 비교, 지도, 역세권 시세, 주거비 부담률, 채용 현황 · 신호 |
| 플랫폼 | 반응형 웹 (데스크톱 · 모바일 브라우저) |

### 제외

- 회원가입, 로그인, 즐겨찾기 등 계정 기능
- 기업 리뷰 작성 · 수집
- 채용공고 본문 저장 · 재배포
- 직무별 · 개인별 연봉 산출 (항상 회사 평균의 추정치 · 하한으로만 표시)
- 단독 · 다가구 전월세, 서울 외 지역 전월세
- 실시간 부동산 매물 정보 (민간 플랫폼 크롤링 · 매물 연결 없음)
- 유료 기능, 광고
- LLM · RAG 등 AI 기능
