## 1. 우선순위 기준

| 등급 | 기준 | 처리 |
|---|---|---|
| **높음** | 사용자가 틀린 숫자 · 판정을 보거나, 시연 흐름이 막힌다 | 발표 전에 고친다 |
| **중간** | 동작은 맞지만 느리거나 헷갈린다 | 시간이 되면 발표 전에, 아니면 한계로 말한다 |
| **낮음** | 사용자에게 보이지 않는 정리 · 리팩터링 | 마감 뒤 |

상태: **열림**(아직 처리 안 함) · **해결**(PR 병합) · **우회**(원인은 그대로, 피하는 방법) · **보류**(마감 뒤) · **대체**(다른 방법으로 요구를 채움)

## 4. 새 이슈를 적을 때

- ID는 `I-NN`으로 이어서 붙인다. 등급 · 상태 · 영역 · 이슈 · 원인 · 제안을 적는다.
- 고치면 상태를 "해결"로 바꾸고 PR 번호를 적는다. 에러 · 버그였으면 troubleshooting.md에 TS 항목도 남긴다(팀 규칙).
