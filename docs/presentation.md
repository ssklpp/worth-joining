## 4. 설계

- **3계층 DB:** raw(원본 보존) → core(정규화 · 좌표) → mart(미리 집계). API는 mart만 읽는다.
- **멱등 적재:** 같은 파일은 체크섬으로 건너뛰고, 같은 행은 `row_hash` · `ON DUPLICATE KEY UPDATE`.
- **배포:** Railway에 cron이 없으므로 로컬에서 적재 · 검증 → 덤프로 반영.
- 그림: README의 시스템 구조(mermaid)

## 5. 핵심 SQL ① 빈 달이 있는 시계열

- 퇴사율 = 상실자 ÷ **직전 달** 가입자. 회사가 한 달 빠지면 `LAG`는 두 달 전 값을 가져온다.
- `prev_ym = PERIOD_ADD(snapshot_ym, -1)`일 때만 계산하고 아니면 NULL. 그래프도 그 달에서 선을 끊는다.

```sql
CASE WHEN LAG(snapshot_ym) OVER w = PERIOD_ADD(snapshot_ym, -1)
     THEN lost / NULLIF(LAG(members) OVER w, 0) END AS quit_rate
```

## 6. 핵심 SQL ② 업종 안 백분위와 표본 부족

- 서울 회사의 60.8%가 가입자 10명 미만이다. 이들을 분포에 넣으면 큰 회사의 백분위가 흔들린다.
- `PARTITION BY industry_code, 지표 IS NULL OR small`로 따로 나눠 백분위 0을 받지 않게 하고, 표본 부족은 NULL.

## 7. 핵심 SQL ③ 역세권 공간 조인

- 역 500m 안 건물, 회사 1km 안 역 3곳. `ST_Distance_Sphere`만 쓰면 전체 스캔 → `MBRContains(ST_Buffer)`로 후보부터.
- 같은 조인을 윈도 함수 쿼리 안에 넣었더니 MariaDB 11.4가 공간 인덱스를 버렸다(기간 하나 150 ~ 320초). 역-건물 쌍을 먼저 만들어 **0.9초**.

- 고르는 규칙을 먼저 정했다(서울 본사 상장사, 업종 중분류마다 가입자 최다). 대기업뿐이라는 한계도 함께 말한다.

## 9. 결과 ② 화면 시연 순서

1. 지도 메인: 시청 주변 핀 → 지표 토글(증감 → 퇴사율 → 연봉)
2. 검색 "우아한형제들" → 상세: 결과표, 근처 역 3곳과 주거비 부담률(월급의 14 ~ 20%)
3. 비교에 담기 3곳 → 비교 패널 지수 그래프
4. 점선 핀(대략 위치) 하나를 눌러 안내 문장 보여 주기

- 응답 시간(로컬 부하 20명): 상세 p95 8ms, 검색 6ms, 지도 270ms. 좌표 100%, 전월세 건물 좌표 99.92%.

## 10. 트러블슈팅 (SPEC이 꼽은 4가지 + 실제로 겪은 것)

| 주제 | 무엇이 문제였나 | 어떻게 풀었나 |
|---|---|---|
| CHAR 생성 컬럼 | MariaDB는 `CHAR` 원본의 생성 컬럼을 오류 1901로 거부 | 원본을 `VARCHAR`로, 함수 인덱스 대신 생성 컬럼 + 일반 인덱스 |
| 빈 달 처리 | `LAG`만 쓰면 빠진 달을 건너뛴 비율이 나옴 | `PERIOD_ADD`로 직전 달인지 확인, 그래프는 선을 끊음 |
| 공간 인덱스 | 윈도 함수 안 공간 조인이 인덱스를 안 씀, 숫자 좌표는 인덱스 없음 | 쌍을 먼저 만들기, 위도 · 경도 범위로 먼저 거르기(refresh 5분 → 35초, TS-025) |
| 대표 사업장 중복 | 모든 사업장으로 회사-역 순위를 매기면 같은 역이 겹쳐 1순위가 사라짐 | 회사마다 대표 사업장 좌표 하나(`company_location`)로만 순위 |
| 좌표 API 한도 | juso가 몰아 부르면 `E0007`을 정상 응답으로 줘 실패로 캐시됨(TS-022) | 재시도 · 간격, 일시 오류는 캐시 안 함 → 최종적으로 출입구 파일로 API 없이 16초 |
| 전각 괄호 | "（주）"가 정규화되지 않아 같은 회사가 둘로 나뉨(TS-016) | NFKC 정규화 후 다시 만듦 |

## 11. 한계

- 추정 연봉은 회사 평균의 하한이다. 개인 · 직무별 연봉이 아니다.
- 서울 사업장만, 공개 기준 미만(법인 3인 · 개인 10인) 회사는 없다.
- 회사 위치는 약 1.2만 곳만 건물 단위, 나머지는 도로 · 동 중심(본사 대비 중앙값 305 · 567m).
- 전월세는 신고된 계약 기준, 아파트 · 단독다가구 제외, 전환율은 연립다세대 값 하나.
- 사람인 채용 연계는 API 승인을 기다리는 중이다.
