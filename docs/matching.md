# DART 매칭 결과

국민연금 서울 회사(`company`)와 OpenDART 법인(`dart_corp`)을 연결한 결과(SPEC Phase 5-6). 측정일 2026-10-12, 국민연금 2026-08 기준, `python -m pipeline.dart.match`.

## 요약

| 지표 | 값 |
|---|---|
| **상장사 매칭률** (본사 서울, 스팩 · 리츠 · 투자회사 제외) | **972 / 1,406 = 69.1%** |
| 서울 회사 중 연결된 회사 (최신 월 가입자 1,000명 이상) | 307 / 392 = 78.3% |
| 〃 (100명 이상) | 2,858 / 4,226 = 67.6% |
| 〃 (10명 이상) | 9,935 / 49,501 = 20.1% |
| 〃 (전체 `mart_company_summary`) | 13,158 / 126,407 = 10.4% |
| 연결 건수 | 정확 13,067, 유사 133 (그중 99건은 영문 · `&`를 한글로 읽으면 이름이 같다) |

비상장 소규모 회사는 대부분 DART 공시 대상이 아니라 연결되지 않는 것이 정상이다. 재무 · 공시 정보가 의미 있는 상장사와 큰 회사 기준으로 본다.

## 매칭 순서

`pipeline/dart/match.py`. SPEC 6장 매칭 순서를 따르고, 유사 단계에 두 규칙을 더했다.

1. **정확(`exact`, 1.000):** 사업자번호 앞 6자리(`dart_corp.bizr6 = company.biz_no6`)와 정규화 이름(`normalize_name`)이 모두 같다.
2. **유사(`fuzzy`, 점수 ÷ 100):** 1에서 안 된 회사를 같은 사업자번호 6자리의 법인과만 비교한다. rapidfuzz `token_sort_ratio ≥ 85`.
   - 비교 전에 `&`는 "앤"으로, 영문 대문자는 한글 읽기(A → 에이, LG → 엘지)로 바꾼다.
   - 85 ~ 89점은 한쪽 이름이 다른 쪽으로 시작할 때만 연결한다. 90점 이상은 그대로 연결한다.
3. 그 외는 연결하지 않는다. 후보가 여럿이면 상장사, `corp_code` 순. `manual` 연결은 다시 계산하지 않는다.

### 영문 · `&`를 한글로 읽는 이유

서울 본사 상장사 중 연결되지 않은 법인을 살펴보니, 사업자번호 6자리가 같은 회사는 있는데 이름 표기가 달랐다. DART는 영문, 국민연금은 한글로 쓰는 경우가 많다.

| DART | 국민연금 |
|---|---|
| LG디스플레이 | 엘지디스플레이(주) |
| CJ대한통운 | 씨제이대한통운(주) |
| GS건설 | 지에스건설(주) |
| F&F | 주식회사에프앤에프 |
| 삼성E&A | 삼성이앤에이(주) |

이 규칙으로 상장사 101곳이 더 연결됐다.

### 85 ~ 89점에 앞부분 일치를 요구하는 이유

규칙을 넣기 전 1.0 미만 유사 연결 60건을 모두 확인했더니 약 14건이 틀렸고, 모두 85 ~ 89점이었다.

| 회사 | 잘못 연결된 법인 | 점수 | 원인 |
|---|---|---|---|
| 봉천새마을금고 | 은천새마을금고 | 85.7 | 새마을금고 · 신협은 같은 사업자번호 6자리를 많이 쓴다 |
| 구로2동새마을금고 | 구로5동새마을금고 | 88.9 | 〃 |
| (주)한오션 | 한화오션 | 85.7 | 비슷한 이름의 다른 회사 |
| (주)지나인테크 | 나인테크 | 88.9 | 〃 |

같은 구간의 맞는 연결은 대부분 국민연금 쪽에 지점 · 직군 접미사가 붙은 형태였다("(주)엘지유플러스(영업) → LG유플러스", "(주)신세계-2 → 신세계"). 그래서 이 구간은 한쪽 이름이 다른 쪽으로 시작할 때만 연결한다. 규칙을 넣은 뒤 남은 1.0 미만 유사 연결 34건을 모두 확인했고 틀린 연결은 없었다. 대신 "리즈인터내셔널 ↔ 리즈인터내셔날"처럼 철자가 조금 다른 몇 건은 놓친다.

## 연결되지 않은 서울 본사 상장사 434곳

| 원인 | 예 |
|---|---|
| 오래전에 상장 폐지됐지만 corpCode.xml에 종목코드가 남은 법인 | 동신제약, 텔슨정보통신 |
| 국민연금 상호가 DART 이름과 크게 다르거나 뒤에 다른 말이 붙음 | 대한약품 ↔ 대한약품공업(주), IPARK현대산업개발 ↔ 아이파크현대산업개발 |
| 서울에 국민연금 사업장이 없음(본사 주소만 서울) | — |

부분 일치(`partial_ratio`)를 허용하면 일부를 더 잡지만 "스피어 ↔ 스피어코퍼레이션" 같은 잘못된 연결이 늘어 넣지 않았다. 중요한 회사가 빠지면 `match_type='manual'`로 직접 넣는다.

## 수집 범위와 한도

- `dart_corp` 119,601개 중 company.json을 부른 법인은 상장사 전체(3,998)와 정규화 이름이 서울 회사와 같은 법인이다. 사업자번호는 company.json으로만 얻으므로, 부르지 않은 법인은 연결 대상이 아니다.
- 2026-10-12에 19,998건을 받고 하루 한도(20,000건)에 닿았다. 남은 2,854건은 다음 날 `python -m pipeline.dart.company_info`로 이어 받고 매칭을 다시 실행한다.
- 해외 법인은 사업자번호 자리에 현지 번호가 와서 비워 둔다(troubleshooting TS-017).
