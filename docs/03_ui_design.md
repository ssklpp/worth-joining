# 화면 디자인 가이드

| 항목 | 내용 |
|---|---|
| 대상 | T4 프론트엔드 (`web/`), API 응답 필드를 정하는 T3 |
| 시안 | [`docs/mockups/map-home.html`](./mockups/map-home.html) (메인: 지도 + 패널), [`docs/mockups/company-detail.html`](./mockups/company-detail.html) (이전안: 상세 단독 화면). 브라우저로 열면 됨. 가상 데이터 |
| 상태 | 초안 · 2026-10-08 |

SPEC 9장(화면)의 구성과 문구 규칙을 바꾸지 않고, 그 위에 **보이는 모양**을 정한다. SPEC과 충돌하면 SPEC을 따른다.

---

## 1. 콘셉트: 회사 건강검진 결과지

건강검진 결과지는 측정값을 **기준 범위** 위에 찍고 "판정"과 "참고"를 붙인다. 이 서비스도 같은 일을 한다.

| 결과지 | 이 서비스 |
|---|---|
| 측정값 | 12개월 증감률, 연간 퇴사율, 추정 연봉 |
| 기준 범위 | 같은 업종의 p25~p75 |
| 판정 | 업종 안 백분위("업종 상위 12%") |
| 참고 사항 | `flags` (하한 추정, 표본 부족, 짧은 이력, 최근 자료 없음) |
| 검사일 | 데이터 기준월 `as_of` |

눈에 띄는 요소는 **기준 범위 막대 하나**로 정한다. 나머지(머리글, 표, 버튼)는 조용하게 둔다.

### SPEC 9장과 다른 점

SPEC 9장은 "체력 카드 3개(백분위 막대)"라고 적고 있다. 지표 3개와 백분위 막대라는 내용은 같고, **모양만 카드 3개 대신 결과표의 행 3개**로 한다. 카드를 나란히 놓으면 업종 범위와 회사 값을 같은 축에서 비교하기 어렵고, 흔한 대시보드처럼 보이기 때문이다. SPEC 문구 수정은 팀장이 판단한다.

## 2. 색 토큰

강조색은 **볼펜 파랑 하나**이고, **회사 값 표시**(막대의 점, 그래프 선)와 포커스 표시에만 쓴다. 버튼은 잉크색이다.

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| `--paper` | `#F6F8FA` | `#111920` | 페이지 바탕 |
| `--surface` | `#FFFFFF` | `#18222B` | 결과표 면 (면을 가진 요소는 결과표뿐) |
| `--ink` | `#1E2A36` | `#E3EAF0` | 본문, 버튼 |
| `--muted` | `#5A6A79` | `#93A3B2` | 단위, 설명, 업종 중간값 눈금 |
| `--rule` | `#DCE3EA` | `#2A3743` | 구분선, 막대 바탕 |
| `--band` | `#D8E6E1` | `#2B4A42` | 업종 중간 50% 구간 |
| `--pen` | `#1D5CB8` | `#7FB0FF` | 이 회사 값, 포커스 |
| `--pen-soft` | `#C9DAF3` | `#27426B` | 이 회사 값의 범위 (주거비 부담률 p25~p75) |
| `--water` | `#E1ECF5` | `#1A2A38` | 시안 약도의 강 (실제 서비스는 네이버 지도) |
| `--caution` | `#8A5F0F` | `#E2B65E` | 참고 표시 글자 |
| `--caution-bg` | `#FBF3E2` | `#2C2516` | 참고 표시 바탕, 그래프의 빈 달 |

- 좋음/나쁨을 초록/빨강으로 칠하지 않는다. 퇴사율이 낮은 게 늘 좋은 건 아니고, 판정은 글로 쓴다.
- 다크 모드는 토큰만 바꾼다. 컴포넌트에 색을 직접 쓰지 않는다.

## 3. 글꼴

- **IBM Plex Sans KR** 한 가족만 쓴다(400 · 500 · 600 · 700). Next.js에서는 `next/font/google`으로 불러온다.
- 대체 글꼴: `"Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`
- 숫자가 세로로 줄 서는 곳(측정값, 표, 그래프 축)은 `font-variant-numeric: tabular-nums`, 표의 숫자 열은 오른쪽 정렬.
- 고정폭(모노스페이스) 글꼴은 쓰지 않는다.

| 단계 | 크기 | 쓰임 |
|---|---|---|
| xxl | 28px / 700 | 회사 이름 |
| xl | 21px / 600 | 구획 제목, 측정값 |
| l | 17px / 600 | 소제목, 로고 |
| m | 15px / 400 | 본문 |
| s | 13px | 설명, 표, 버튼 |
| xs | 12px | 축 라벨, 측정값 아래 단위 설명 |

## 4. 레이아웃

- 본문 최대 폭 880px, 왼쪽 정렬 한 단. 좌우 여백은 최소 16px(시안은 20px).
- 둥근 모서리는 결과표 6px, 버튼과 입력창 4px만 쓴다. 그림자는 쓰지 않는다.
- 구획 사이 간격은 `gap`으로 준다(시안 32px). 요소마다 margin을 따로 주지 않는다.

### 결과표 행

```
넓은 화면 (641px 이상)
| 항목 4.5rem | 측정값 9.5rem | 업종 안 위치 (남는 폭) | 판정 9rem |
| 성장        | +18.3%        | ░░▓▓▓▓│▓▓░░░░●░░        | 빠르게 늘고 있음 |
|             | 12개월 전보다…  | -30%            +40%    | 업종 상위 12%    |

좁은 화면 (640px 이하)
| 성장                          빠르게 늘고 있음 |
|                                  업종 상위 12% |
| +18.3%  12개월 전보다 가입자 증감               |
| ░░▓▓▓▓│▓▓░░░░●░░                              |
```

### 기준 범위 막대

| 요소 | 모양 | 데이터 |
|---|---|---|
| 바탕선 | 2px `--rule` | 축 전체 |
| 범위 띠 | 높이 16px `--band` | 업종 p25 ~ p75 (`/industries/{code}/distribution`) |
| 중간값 눈금 | 2px × 22px `--muted` | 업종 p50 |
| 회사 점 | 지름 16px `--pen`, 3px `--surface` 테두리 | 회사 값 |
| 점선 꼬리 | 2px 점선 `--pen`, 점에서 오른쪽으로 | 하한 추정(`salary_is_lower_bound`)일 때만 |
| 축 라벨 | 12px `--muted`, 양 끝 | 축의 최소 · 최대 |

- 위치는 모두 같은 선형 축 하나로 계산한다: `left = (값 − 최소) ÷ (최대 − 최소) × 100%`.
- 축 범위는 지표별로 고정한다(시안: 성장 −30%~+40%, 퇴사율 0%~60%, 연봉 2,000만~8,000만 원). 축 밖의 값은 끝에 붙이고 측정값 글자로 실제 값을 보여준다. 실제 데이터 분포를 보고 T2와 범위를 정한다.
- 막대에는 `role="img"`와 `aria-label`로 범위와 회사 값을 글로 넣는다.

## 5. 화면 구조: 지도가 메인

지도 기반 채용 탐색 화면(예: 원티드 포지션 맵)처럼 **지도가 첫 화면**이고, 회사 상세는 지도 옆 패널에서 연다. SPEC 9장은 검색(`/`)을 메인, 지도를 `/map`으로 두고 있으므로 SPEC 수정 여부는 팀장이 판단한다.

```
┌ 다닐만한가  [회사 검색]  업종 ▾  지역 ▾  [증감|퇴사율|연봉|공고 수]  □ 채용 중만 ┐
├──────────────┬───────────────────────────────────────────────┤
│ 패널          │  지도                                     [+][−][전체] │
│ 목록 모드:    │      (+18.3%)        ▢한빛역                      │
│  지도 안의    │            (−6.1%)                                  │
│  회사 12곳 ▾  │   (+4.9%)          (+21.4%)                         │
│  ─ 예시소프트 │                                                   │
│  ─ 예시클라우드│ [비교함 2/3 예시소프트× 예시클라우드× (비교하기)]  [범례] │
└──────────────┴───────────────────────────────────────────────┘
```

| 요소 | 동작 |
|---|---|
| 패널: 목록 (폭 360px) | 지금 지도 범위 안에 있는 회사만. 지도를 옮기거나 확대하면 바로 갱신. 정렬: 가입자 · 증감 · 퇴사율 · 연봉 · 마감 임박(연동 후). 항목에 마우스를 올리면 지도 태그가 강조되고 회사 이름이 펼쳐진다 |
| 패널: 상세 (폭 460px) | 지도 태그나 목록 항목을 누르면 연다. "목록으로"와 Esc로 돌아간다. 내용은 결과지 순서 그대로(기본 정보 → 체력 → 채용 → 근처 주거비 → 추이 → 재무 → 읽는 법 → 출처). URL은 `/companies/{id}`(시안은 `#c{id}`) |
| 패널: 비교 (폭 460px) | 비교함에서 "비교하기". 지수 그래프 + 회사별 열 표(가입자, 증감, 퇴사율, 연봉, 공고, 가까운 역 월세, 부담률) |
| 지도 태그 | 둥근 태그에 선택한 지표 값. 아래 꼭지가 위치를 가리킨다. 테두리 `--pen`. 대략 위치는 점선, 가입자 10명 미만은 흐린 색, 선택된 회사는 채운 태그 + 이름 |
| 상세를 열 때 | 지도가 회사로 이동 · 확대(약 3.6km 폭)하고, 1km 점선 원과 연결된 역의 500m 원을 그린다. 움직임은 `prefers-reduced-motion`이면 생략 |
| 비교함 | 지도 왼쪽 아래에 떠 있는 막대. 담은 회사 칩(×로 빼기)과 "비교하기"(2곳 이상일 때) |
| 좁은 화면 | 지도(화면 높이의 56%)가 위, 패널이 아래. 회사를 열면 패널로 스크롤 |

## 6. 화면별 적용

| 화면 | 적용 |
|---|---|
| 검색 `/` | 첫 요소는 큰 검색창 하나. 결과 행에 회사명 + 시 · 구 + 업종명으로 동명 회사를 구분하고, 지표 칸마다 기준 범위 막대를 작게(높이 12px, 라벨 없음) 넣는다 |
| 회사 상세 `/companies/[id]` | 시안 그대로: 기본 정보 → 결과표 → 가입자 추이 → 월별 입퇴사 표 → 재무 → 읽는 법 → 하단 출처 |
| 지도 `/map` | 핀 색은 `--pen` 하나. 지표 토글에 따라 핀 안의 값만 바뀐다. 대략 위치(`approx_location`)는 속이 빈 핀 |
| 계산 방법 `/methodology` | 본문 폭 65자 안팎의 읽는 화면. 결과표 장식은 쓰지 않는다 |

### 확장 구획 (시안에 포함)

| 구획 | 구성 | 규칙 |
|---|---|---|
| 채용 현황 (상세) | 채용 신호 문장 → 공고 목록(제목, 경력 · 근무지, 마감일과 남은 날, 제시 연봉, 원문 링크) → 공고 연봉 비교 막대 | 신호는 라벨 칩이 아니라 문장으로 쓰고 근거 숫자를 붙인다. 근무지는 회사 지역과 다를 때만 적는다. 공고 연봉은 막대 위의 **테두리 상자**(`--ink`)로, 업종 범위 · 회사 점과 같은 축에 둔다. 하단에 "채용정보 제공: 사람인" |
| 사람인 연동 전 | 채용 구획에 사람인 검색 바로가기 버튼만 | Phase 10 전까지의 실제 화면 |
| 회사 근처 주거비 (상세) | 기간 버튼(6/12/24개월) → 약도 + 역 행 3개 | 역 행: 역 이름 · 노선 · 거리, 환산 월세 중간값(p25~p75), 전세 중간값, 계약 수, 부담률 막대(0~50%, 범위는 `--pen-soft`, 중간은 회사 점). 24개월로 넓힌 역은 참고 상자 |
| 약도 | 회사 점, 1km 점선 원, 역 사각형과 500m 회색 원, 축척 막대 | 거리를 실제 축척으로 그린다. 실제 서비스에서는 네이버 지도로 바꾼다 |
| 지도로 비교 `/map` | 필터(업종, 지역, 핀 값) → 지도 + 오른쪽 요약 패널 → 비교(지수 그래프 + 표) | 핀 위에 선택한 지표 값을 쓴다. 비교 표에 진행 중 공고 수, 가까운 역 환산 월세, 주거비 부담률 열을 더한다(연동 전에는 숨김). 200곳 초과는 상태 문장으로 안내 |

## 7. 상태와 `flags` 표현

| 상태 | 화면 | 문구 |
|---|---|---|
| `salary_is_lower_bound` | 측정값 앞에 `≥`, 막대에 점선 꼬리, 행 아래 참고 상자 | 국민연금 소득 상한 때문에 실제보다 낮게 나올 수 있습니다. |
| `small_sample` | 회사 점을 속이 빈 원으로, 판정 대신 참고 상자 | 가입자가 10명 미만이라 비율이 크게 흔들릴 수 있습니다. |
| `short_history` | 성장 행의 측정값 "계산 안 함", 점 없음 | 12개월 전 자료가 없어 성장률을 계산하지 않았습니다. |
| `stale` | 결과표 · 그래프 · 표를 모두 숨기고 안내 상자만 | {last_seen_ym} 이후 국민연금 자료에 없는 회사입니다. 폐업했거나 국민연금 사업장에서 탈퇴했을 수 있습니다. |
| `name_matched` | 재무 구획 설명 문장 | 회사 이름으로 연결했습니다. 다른 회사일 수 있습니다. |
| `approx_location` | 지도 핀 모양, 팝업 문장 | 주소가 동 단위까지만 있어 대략적인 위치입니다. |
| `period_extended_to_24m` | 역 시세 설명 문장 | 계약이 적어 최근 24개월로 넓혀 계산했습니다. |
| 로딩 | 구획 자리에 같은 높이의 빈 틀 | (문구 없음) |
| 오류 | 구획 자리에 안내와 버튼 | 정보를 불러오지 못했습니다. 다시 시도해 주세요. [다시 시도] |
| 검색 결과 없음 | 안내 | "{검색어}"와 일치하는 회사가 없습니다. 가입자 3명 미만 법인이나 10명 미만 개인사업장은 공개되지 않습니다. 사업자번호 앞 6자리로도 찾아보세요. |

참고 상자는 `--caution` 글자와 `--caution-bg` 바탕을 쓴다. 왼쪽 강조 막대는 붙이지 않는다.

## 8. 그래프 (Recharts)

- 가입자 추이는 꺾은선 하나, 색은 `--pen`, 굵기 2.5px. 마지막 점만 크게(반지름 5) 하고 값 라벨("142명")을 붙인다.
- **빈 달은 선을 끊는다.** `/companies/{id}/trend`는 자료가 있는 달만 내려줄 수 있으므로, 프론트에서 기간 안의 모든 달을 채우고 없는 달은 `members: null`로 넣는다. `<Line connectNulls={false} />`. 빈 달 위치에는 `--caution-bg` 띠와 "자료 없음" 라벨.
- 격자는 가로선만 `--rule`. 축 글자는 `--muted` 11px. 범례는 선이 하나뿐이라 넣지 않는다.
- 비교 화면의 지수 그래프(12개월 전 = 100)는 회사 3곳을 구분해야 하므로 예외로 3색이 필요하다. `--pen`, `--ink`, `--muted`에 선 모양(실선, 긴 점선, 짧은 점선)을 함께 써서 색 없이도 구분되게 한다.

## 9. 문구

- 사용자가 아는 말로 쓴다. "표본 부족" 대신 "가입자가 10명 미만이라…", "stale" 대신 "최근 자료 없음".
- 버튼은 동작을 그대로 말한다: "비교에 담기" → 누르면 "비교에서 빼기", 상단 "비교함 1/3".
- 숫자의 한계를 숨기지 않되 사과하지 않는다. 오류 문구는 무엇이 안 됐고 어떻게 하면 되는지를 말한다.
- 피할 것: 대문자 영문 라벨, 제목 위의 작은 장식 라벨, "A · B · C"처럼 가운뎃점으로 이은 메타 정보(항목을 나눠 보여준다), 버튼 끝의 `→`, 이모지, 실제 순서가 아닌 내용에 붙인 01 / 02 / 03 번호.

## 10. 접근성과 반응형

- 키보드 포커스는 `--pen` 2px 외곽선으로 항상 보이게 한다.
- 색만으로 뜻을 전하지 않는다. 판정은 글로, 하한은 `≥`와 점선으로, 대략 위치는 핀 모양으로 함께 표시한다.
- 휴대폰 폭에서 결과표 행은 세로로 쌓는다. 넓은 표와 그래프만 자기 영역 안에서 가로 스크롤한다(SPEC 9장).
- 움직임은 쓰지 않는다. 쓸 일이 생기면 `prefers-reduced-motion`을 지킨다.
